# gtum Sprint 16 로고 결정 / Sprint 16 Logo Decision

## 목적 / Purpose

### 한국어

이 문서는 `Sprint 16`에서 검토한 로고 시안과 최종 선택 결과를 기록한다.

### English

This document records the logo directions reviewed in `Sprint 16` and the final selection.

## 선정 결과 / Decision

### 한국어

- 현재 선택안은 `Concept A`다.
- 선택 이유
  - 현재 제품 baseline인 `left rail + split workbench + agent workspace`를 가장 자연스럽게 담는다.
  - 작은 크기에서도 rail, block, prompt, signal이 비교적 안정적으로 읽힌다.
  - 기존 `gtum` 자산과의 연결을 너무 끊지 않으면서 정리된 형태를 만든다.

### English

- `Concept A` is the selected direction.
- Why it was chosen
  - it expresses the current `left rail + split workbench + agent workspace` baseline most naturally
  - rail, block, prompt, and signal remain readable at small sizes
  - it refreshes the brand without severing continuity with the previous `gtum` mark

## Concept A: Split Rail

### 한국어

- 상태
  - `선택됨`
- 방향
  - 현재 workbench 구조를 가장 직접적으로 보여주는 기본안
- 특징
  - 강한 outer frame
  - 명확한 left rail
  - split block 느낌의 상단 structure
  - terminal prompt와 underline
  - agent signal dot

### English

- Status
  - `selected`
- Direction
  - the clearest baseline for the current workbench structure
- Traits
  - strong outer frame
  - clear left rail
  - upper split-block structure
  - terminal prompt plus underline
  - agent signal dot

## Concept B: Prompt Beacon

### 한국어

- 방향
  - 더 icon-first이고 agent orchestration 느낌이 강한 대안
- 특징
  - shell + rail
  - prompt 중심 구조
  - signal arc
  - 작은 크기에서 강한 silhouette

### English

- Direction
  - the more icon-first alternative with stronger orchestration tone
- Traits
  - shell + rail
  - prompt-centered structure
  - signal arc
  - strong silhouette at small sizes

## Concept C: Pane Grid

### 한국어

- 방향
  - split workbench와 pane 구조를 가장 강하게 드러내는 대안
- 특징
  - 좌측 rail
  - 상단과 하단의 pane block
  - execution tile
  - 작은 크기에서도 구성이 잘 남는 block contrast

### English

- Direction
  - the strongest split-workbench alternative
- Traits
  - left rail
  - upper and lower pane blocks
  - execution tile
  - strong block contrast at small sizes
