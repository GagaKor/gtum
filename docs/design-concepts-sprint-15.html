Split Mission Control Workspace

하단 패널은 제거하고, 중앙 workbench 자체가 분할 가능한 구조로 바뀝니다. 프로젝트 관리는 왼쪽으로, 실제 대화와 작업 위임은 오른쪽 `에이전트 작업창`으로 옮깁니다. 터미널은 고정 메인 패널이 아니라 `+`로 여는 탭이지만, 열리면 코드 옆에 바로 나란히 둘 수 있어야 합니다.

상단

프로젝트 탭은 두지 않습니다. `현재 작업`, `연결 상태`, `활성 에이전트`, `승인 대기`만 남깁니다.

왼쪽

`프로젝트`, `탐색기`, `검색`, `소스`, `아웃라인`을 VS Code처럼 접고 펼칩니다.

중앙

빈 workbench에서 시작하고 `+`로 탭을 만든 뒤, 상하좌우 분할로 코드를 나란히 봅니다.

오른쪽

상태판이 아니라 `에이전트 작업창`입니다. 요청, 답변, 상태, 승인 항목이 모두 있습니다.

탭 모양

탭은 큰 버튼이 아니라 `VS Code`처럼 낮고 가로로 긴 형태로 보여야 합니다.

Split Right / Left / Up / Down

활성 탭을 기준으로 상하좌우 분할을 지원합니다. 각 pane은 독립적인 탭 스택을 가집니다.

탭 이동

코드 탭, 터미널 탭, diff 탭은 pane 간 이동할 수 있어야 합니다. pane를 닫으면 남은 pane이 공간을 회수합니다.

Diff / Test / Preview 의미

`Diff`는 변경 코드 비교, `Test`는 구조화된 테스트 결과, `Preview`는 Markdown이나 렌더링된 결과 화면 미리보기입니다.

프로젝트 관리는 왼쪽

상단에서 프로젝트를 관리하지 않습니다. 프로젝트 전환과 파일 구조 진입은 왼쪽 rail에서 처리합니다.

하단 제거

결과를 보고 싶으면 중앙에서 새 탭이나 split pane으로 엽니다. 기본 하단 패널은 두지 않습니다.
