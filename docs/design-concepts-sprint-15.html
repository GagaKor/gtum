에디터와 에이전트 작업창이 메인이고, 터미널은 탭으로 들어가는 구조

이번 시안은 선택지를 더 만드는 대신 하나의 기준안을 정제한 버전입니다. 좌측은 `VS Code`처럼 접고 펴는 activity bar, 중앙은 `+`로 탭을 여는 빈 workbench, 우측은 `에이전트에게 일을 주고 답을 받는 창`, 하단은 필요할 때만 여는 기록 drawer입니다.

버린 것

`Project / Branch / Active File` 같은 설명 없는 전역 토큰과 고정 mode 버튼줄을 버립니다.

고정한 것

좌측 activity bar, 중앙 empty workbench, 우측 agent work panel, 하단 hidden drawer.

터미널의 위치

터미널은 기본 주인공이 아니라 `+`로 여는 강한 탭입니다. agent도 쉽게 열 수 있어야 합니다.

오른쪽 패널

상태판이 아니라 실제 요청 입력, 답변, 승인 흐름이 있는 `에이전트 작업창`입니다.

첫 진입 상태

프로젝트를 열고 중앙 workbench에서 필요한 탭을 추가하는 순간이 분명해야 합니다. 용어는 쉽고, 행동은 바로 보여야 합니다.

empty workbench plus-driven tabs agent panel ready
