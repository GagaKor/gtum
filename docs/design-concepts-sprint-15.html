에디터와 에이전트 보드가 메인이고, 터미널은 모드인 구조

이번 시안은 방향을 다시 맞춘 버전입니다. 메인은 `VS Code`처럼 읽기 좋은 코드 에디터와 `conductor`처럼 상태가 잘 보이는 에이전트 관리이며, 터미널은 항상 전면 고정이 아니라 `Code / Diff / Test / Terminal / Preview` 같은 workbench tab으로 들어갑니다.

이전 시안의 문제

터미널의 배치를 너무 크게 다뤄서, 실제로 중요한 에디터와 agent board 우선순위가 약했습니다.

이번 공통 기준

좌측 explorer, 중앙 editor workbench, 우측 conductor형 agent board, 하단 secondary drawer입니다.

터미널의 위치

터미널은 메인 무대가 아니라 필요할 때 전환하는 강한 mode입니다. 세션 연속성은 유지합니다.

권장안

`B. Mission Control`이 사용자 요구와 가장 가깝습니다. conductor형 운영감이 가장 강합니다.

A

Editor Board

가장 VS Code에 가까운 구조입니다. 익숙한 editor workbench를 중심에 두고, 오른쪽에 agent board를 붙입니다.

VS Code familiarity 낮은 구현 리스크 editor-first

좋은 경우: editor experience를 가장 우선하고 싶을 때.
